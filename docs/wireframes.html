Wireframes · low-fidelity · living document

govcms — the CMS platform

Layout and flow for the admin product — the tool editors and admins use. These are intentionally grayscale: they pin down screens, structure, and navigation before any visual design. The real look is the indigo admin-ui brand.

admin product not the public sites Public/citizen sites are a separate, RISA-conformant design system — wireframed separately later.
Read me

These are wireframes, not designs. Gray = structure. The single blue accent marks the active nav item and the primary action on each screen, so you can read hierarchy. Placeholder bars stand in for real text and images.

Every screen maps to something already decided in the implementation plan — content types, immutable versions, per-tenant roles, workflow, multilingual. Nothing here is new scope; it's the plan made visible.
